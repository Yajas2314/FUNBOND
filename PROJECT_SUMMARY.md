## 🎬 Premium Animation Features

### Global Animations
- **Custom Cursor:** Follows mouse with 0.1s delay (desktop only)
- **Floating Particles:** 50 ambient particles with fade animation
- **Scroll Progress:** Top bar indicating page scroll position
- **Page Transitions:** Smooth fade and slide animations

### Section-Specific Animations
- **Hero:** 3D perspective, floating items, glow pulse
- **Cards:** Scale, rotate, glow on hover
- **Counters:** Number increment with GSAP easing
- **Timeline:** Slide-in with alternating directions
- **Carousel:** Fade transition between slides
- **Accordion:** Height collapse/expand
- **Gallery:** Scale and modal pop effects

### Easing Functions
- `cubic-bezier(0.4, 0, 0.2, 1)` - Standard smooth transition
- `cubic-bezier(0.4, 0, 0.6, 1)` - Pulse effect
- `power2.out` - Eased out quadratic
- `linear` - Constant speed

## 🎨 Design System

### Color Palette
```
Primary Colors:
- Cyan-400: #22d3ee (Primary accent)
- Purple-500: #a855f7 (Secondary accent)
- Magenta-600: #db2777 (Tertiary accent)

Background Colors:
- Slate-950: #020617 (Dark background)
- Slate-900: #0f172a (Secondary background)
- Slate-800: #1e293b (Tertiary background)

Status Colors:
- Green: Success/Done
- Yellow: Warning/Pending
- Red: Error/Alert
```

### Typography Hierarchy
```
H1: clamp(2.25rem, 5vw, 4.5rem) - Main titles
H2: clamp(1.875rem, 4vw, 3.75rem) - Section titles
H3: clamp(1.5rem, 3vw, 2.25rem) - Subsections
H4: 1.25rem - Card titles
Body: 1rem - Regular text
Small: 0.875rem - Helper text
```

### Spacing Scale
```
xs: 0.5rem (8px)
sm: 1rem (16px)
md: 1.5rem (24px)
lg: 2rem (32px)
xl: 2.5rem (40px)
2xl: 3rem (48px)
3xl: 4rem (64px)
```
